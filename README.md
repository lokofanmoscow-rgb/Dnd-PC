# 🐉 Подземелья и Драконы — Боевой стол (D&D 5e для ПК)

Настольная D&D 5-й редакции на компьютере: игровое поле с редактором карт, бестиарий,
создание персонажей, броски инициативы и тактический бой по правилам 5e.
Вся компания играет **за одним ПК** — каждый игрок делает свой ход по очереди (hot-seat),
монстрами управляет ИИ или ведущий.

## ▶️ Как запустить

1. Скачайте файл **[`release/DnD-Battle-Table.exe`](release/DnD-Battle-Table.exe)** (≈75 МБ).
   На странице файла на GitHub нажмите кнопку **Download raw file** (значок ⬇).
2. Запустите его двойным щелчком — установка не нужна (portable-версия, Windows 10/11, 64 бит).
   Первый запуск занимает несколько секунд: программа распаковывается во временную папку.
3. Если Windows покажет «Система Windows защитила ваш компьютер» — нажмите
   **Подробнее → Выполнить в любом случае** (у файла нет платной цифровой подписи).

Персонажи, карты, свои монстры и сохранённые бои хранятся в профиле пользователя
(`%APPDATA%`) и не пропадают между запусками. Их можно выгружать и загружать как JSON-файлы.

## 🎲 Что есть в игре

| Раздел | Возможности |
|---|---|
| **Персонажи** | 9 рас (с подрасами), 12 классов, **уровни 1–20**, **по 2–4 подкласса у каждого класса** (31 подкласс: путь берсерка и тотема, коллегии знаний и доблести, домены жизни/света/войны/бури, круги земли и луны, чемпион/мастер боя/мистический рыцарь, открытая ладонь/тень/четыре стихии, клятвы преданности/древних/мести, охотник/повелитель зверей, вор/убийца/мистический ловкач, драконья кровь/дикая магия, исчадие/архифея/великий древний, воплощение/ограждение/некромантия). Характеристики: стандартный набор, покупка очков (27), бросок 4к6 или вручную; расовые бонусы, увеличения характеристик по уровням класса. Навыки, боевой стиль, доспех (+1…+3), щит, 3 слота оружия, **3 слота артефактов** (30 готовых предметов), зелья, заклинания до 9 уровня. **Своё снаряжение**: в конце списков доспехов, оружия и артефактов — «+ Добавить новый…», где задаются название и характеристики. Портрет из картинки. **«Готовая партия»** — каждый раз 4 случайных героя (расы, классы, подклассы, имена, характеристики, общий случайный уровень 1–10), **«Удалить всех»**. |
| **Бестиарий** | **Весь бестиарий SRD 5.1 — 334 существа** с переводом на русский: от крысы и гоблина до древних драконов, лича, кракена и тарраска. Полные статблоки: черты, действия, реакции, **легендарные действия**, сопротивления и иммунитеты. Поиск, фильтры по типу и опасности. **Свои монстры**: создание с нуля или «своя версия» любого монстра, выбор значка из набора иконок. |
| **Редактор карт** | Кисть, прямоугольник, рамка, заливка, пипетка, ластик, отмена (Ctrl+Z). 33 типа клеток: полы, трава, вода, лава, стены, двери, деревья, мебель и др. **Размер до 120×120**. 6 готовых карт. Экспорт/импорт. Рисовать можно и прямо на доске во время боя («🖌 Карта»). |
| **Бой** | Расстановка жетонов перетаскиванием; **у выбранного участника при подготовке можно изменить максимум хитов и КД** (а во время боя — через меню ведущего). Броски инициативы по очереди (или ввод результата настоящего кубика), полоса инициативы, журнал боя, анимированные броски к20, лоток кубиков (к4…к100, формулы вида `2к6+3`). Сохранение и загрузка боя. |

### Правила 5e, которые учитываются автоматически
- Действие, бонусное действие, реакция и перемещение (диагональ = 5 фт., труднопроходимая местность ×2, полёт, плавание).
- Атака: к20 + бонус против КД, критическое попадание на 20 (у Чемпиона — на 19–20), промах на 1.
- **Преимущество/помеха**: тактика стаи, лежащая цель, невидимость, Уклонение, Помощь, ослепление, отравление,
  опутывание, паралич, стрельба с близкого врага, дальняя дистанция, безрассудная атака и т. д.
- Атаки по возможности, Отход, Рывок, Уклонение, Помощь, Толчок/сбивание с ног, Захват и высвобождение, Встать.
- Урон по видам: сопротивление, иммунитет, уязвимость, немагическое оружие, временные хиты.
- 0 хитов: потеря сознания, спасброски от смерти, стабилизация (Медицина), мгновенная смерть от огромного урона.
- Спасброски с бонусами (Аура защиты паладина, Благословение, расовые преимущества, Легендарное сопротивление).
- Концентрация (спасбросок Телосложения при уроне), 14 состояний с длительностью и повторными спасбросками.
- **Заклинания — все 319 из SRD 5.1** (плюс 9 из прежней версии), с 0 по 9 уровень, с русскими названиями,
  описаниями, временем накладывания, дистанцией, длительностью и компонентами. Ячейки, заговоры (растут с уровнем),
  усиление ячейкой выше, области — сфера, конус, линия, куб, аура. Работают в бою: урон и спасброски,
  **постоянные зоны** (Лунный луч, Облако смерти, Огненная стена, Стена клинков, Чёрные щупальца, Метель…),
  **призыв существ** (Призыв животных, Гигантское насекомое…), **превращение** (Превращение, Облик зверя,
  Изменение облика), **контрзаклинание** реакцией, повторяемые заклинания (Призыв молнии, Пылающий шар,
  Раскалённый металл), оружие из заклинаний (Пламенный клинок, Рука Бигби, Меч Морденкайнена), баффы и
  проклятия (Порча, Полёт, Отражения, Размытый образ, Защита от энергии, Предвидение…), Остановка времени,
  Божественное слово. Заклинания без боевой механики (ритуалы, прорицания, иллюзии) накладываются и выводят
  описание в журнал — их эффект разыгрывает ведущий; заклинания со временем накладывания 1 минута и дольше
  в бою недоступны (по правилам). Таинственный арканум колдуна — без ячеек.
- Умения классов и подклассов до 20 уровня: Ярость и её рост, тотемные духи, Бешенство, Непреклонная ярость,
  приёмы мастера боя, Боевая магия, Дикий облик друида (звери и элементали), Направленный удар, Гнев бури,
  Острое слово, Отражение снарядов, Дрожащая ладонь, Шаг тени, стихийные техники монаха, Клятва вражды,
  Гнев природы, Святой нимб, Вихревая атака, спутник-зверь следопыта, Убийство, Удача, Дикая магия,
  Бросок сквозь ад, Перегрузка, Магическая защита и др.
- Особенности монстров: мультиатака, дыхание и другие способности с перезарядкой, **легендарные действия**
  (в конце хода других существ) и легендарное сопротивление, врождённые заклинания, взгляды, ужасающая
  внешность, захват, яд, истощение максимума хитов, регенерация, поглощение урона (големы), раскалённое тело,
  взрыв после смерти, телепортация, лечение касанием, тактика стаи, кровавое бешенство и т. д.

## ⌨️ Управление в бою
- **Клик по голубой клетке** — переместиться (путь и стоимость видны при наведении).
- **Клик по врагу** — атаковать лучшим доступным оружием; или выберите атаку/заклинание справа и кликните по цели.
- **Правый клик по жетону** — меню ведущего: хиты, урон/лечение, состояния, ИИ/игрок, сторона, телепорт, удалить.
- **Пробел / Enter** — закончить ход, **Esc** — отменить действие, **колесо** — масштаб,
  **правая/средняя кнопка + перетаскивание** — сдвиг карты, **F11** — полный экран.

## 🛠 Сборка из исходников

Нужен [Node.js](https://nodejs.org/) 18+.

```bash
npm install
```

```bash
npm start
```

```bash
npm test
```

```bash
npm run dist:win
```

Последняя команда создаёт `dist/DnD-Battle-Table.exe` (работает и на Linux — без Wine; иконка exe-файла
в этом случае не встраивается). На GitHub есть workflow **«Сборка Windows .exe»** (`.github/workflows/build-windows.yml`):
его можно запустить вручную во вкладке Actions, а при пуше тега `v*` exe автоматически прикрепляется к релизу.

Игру можно открыть и просто в браузере: `src/index.html` (сохранения будут в хранилище браузера).

### Структура
```
electron/main.js        окно приложения (Electron)
src/index.html          интерфейс
src/js/core/            утилиты, кости
src/js/data/            расы, классы, снаряжение, заклинания (spells.js + spells-srd.js), бестиарий (srd-monsters.js), иконки, клетки, карты
tools/srd/              конвертеры бестиария и заклинаний SRD → данные игры (перевод, разбор механики), сборка иконок
src/js/engine/          персонажи, геометрия поля и поиск пути, боевой движок, ИИ монстров
src/js/ui/              экраны: меню, редактор карт, персонажи, бестиарий, бой
tests/                  автотесты правил (node --test)
```
