# 🐉 Подземелья и Драконы — Боевой стол (D&D 5e для ПК)

Настольная D&D 5-й редакции на компьютере: игровое поле с редактором карт, бестиарий,
создание персонажей, броски инициативы и тактический бой по правилам 5e.
Вся компания играет **за одним ПК** — каждый игрок делает свой ход по очереди (hot-seat),
монстрами управляет ИИ или ведущий.

## ▶️ Как запустить

1. Скачайте файл **[`release/DnD-Battle-Table.exe`](release/DnD-Battle-Table.exe)** (≈70 МБ).
   На странице файла на GitHub нажмите кнопку **Download raw file** (значок ⬇).
2. Запустите его двойным щелчком — установка не нужна (portable-версия, Windows 10/11, 64 бит).
   Первый запуск занимает несколько секунд: программа распаковывается во временную папку.
3. Если Windows покажет «Система Windows защитила ваш компьютер» — нажмите
   **Подробнее → Выполнить в любом случае** (у файла нет платной цифровой подписи).

Персонажи, карты, свои монстры и сохранённые бои хранятся в профиле пользователя
(`%APPDATA%`) и не пропадают между запусками. Их можно выгружать и загружать как JSON-файлы.

## 🎲 Что есть в игре

| Раздел | Возможности |
|---|---|
| **Персонажи** | 9 рас (с подрасами), 12 классов, уровни 1–10. Характеристики: стандартный набор, покупка очков (27), бросок 4к6 или вручную; расовые бонусы, увеличение характеристик. Навыки, боевой стиль, доспехи, щит, оружие (в т. ч. магическое +1…+3), зелья, заклинания. Портрет из картинки. Готовая партия в один клик. |
| **Бестиарий** | 50 существ SRD 5.1 — от гоблина и волка до тролля и взрослого красного дракона — со статблоками в стиле dnd.su. Поиск, фильтры по типу и опасности. **Свои монстры**: создание с нуля или «своя версия» любого монстра. |
| **Редактор карт** | Кисть, прямоугольник, рамка, заливка, пипетка, ластик, отмена (Ctrl+Z). 33 типа клеток: полы, трава, вода, лава, стены, двери, деревья, мебель и др. Размер до 60×60. 6 готовых карт. Экспорт/импорт. Рисовать можно и прямо на доске во время боя («🖌 Карта»). |
| **Бой** | Расстановка жетонов перетаскиванием, броски инициативы по очереди (или ввод результата настоящего кубика), полоса инициативы, журнал боя, анимированные броски к20, лоток кубиков (к4…к100, формулы вида `2к6+3`). Сохранение и загрузка боя. |

### Правила 5e, которые учитываются автоматически
- Действие, бонусное действие, реакция и перемещение (диагональ = 5 фт., труднопроходимая местность ×2, полёт, плавание).
- Атака: к20 + бонус против КД, критическое попадание на 20 (у Чемпиона — на 19–20), промах на 1.
- **Преимущество/помеха**: тактика стаи, лежащая цель, невидимость, Уклонение, Помощь, ослепление, отравление,
  опутывание, паралич, стрельба с близкого врага, дальняя дистанция, безрассудная атака и т. д.
- Атаки по возможности, Отход, Рывок, Уклонение, Помощь, Толчок/сбивание с ног, Захват и высвобождение, Встать.
- Урон по видам: сопротивление, иммунитет, уязвимость, немагическое оружие, временные хиты.
- 0 хитов: потеря сознания, спасброски от смерти, стабилизация (Медицина), мгновенная смерть от огромного урона.
- Спасброски с бонусами (Аура защиты паладина, Благословение, расовые преимущества, Легендарное сопротивление).
- Концентрация (спасбросок Телосложения при уроне), 14 состояний с длительностью и повторными спасбросками.
- Заклинания: ячейки, заговоры (растут с уровнем), усиление ячейкой выше, области — сфера, конус, линия, куб,
  аура. Огненный шар, Волшебная стрела, Удержание личности, Усыпление, Лечащее слово, Духовные стражи и др. (~45).
- Умения классов: Ярость, Безрассудная атака, Второе дыхание, Всплеск действий, Скрытая атака, Хитрое действие,
  Невероятное уклонение, Божественная кара, Наложение рук, Вдохновение барда, Шквал ударов, Ошеломляющий удар,
  Изгнание нежити, Оружие дыхания драконорождённого, Ускоренное заклинание и др.
- Особенности монстров: мультиатака, дыхание с перезарядкой 5–6, стойкость нежити, регенерация тролля
  (останавливается огнём/кислотой), паралич гуля, паутина, рывок минотавра, ужасающая внешность дракона и т. д.

## ⌨️ Управление в бою
- **Клик по голубой клетке** — переместиться (путь и стоимость видны при наведении).
- **Клик по врагу** — атаковать лучшим доступным оружием; или выберите атаку/заклинание справа и кликните по цели.
- **Правый клик по жетону** — меню ведущего: хиты, урон/лечение, состояния, ИИ/игрок, сторона, телепорт, удалить.
- **Пробел / Enter** — закончить ход, **Esc** — отменить действие, **колесо** — масштаб,
  **правая/средняя кнопка + перетаскивание** — сдвиг карты, **F11** — полный экран.

## 🛠 Сборка из исходников

Нужен [Node.js](https://nodejs.org/) 18+.

```bash
npm install
```

```bash
npm start
```

```bash
npm test
```

```bash
npm run dist:win
```

Последняя команда создаёт `dist/DnD-Battle-Table.exe` (работает и на Linux — без Wine; иконка exe-файла
в этом случае не встраивается). На GitHub есть workflow **«Сборка Windows .exe»** (`.github/workflows/build-windows.yml`):
его можно запустить вручную во вкладке Actions, а при пуше тега `v*` exe автоматически прикрепляется к релизу.

Игру можно открыть и просто в браузере: `src/index.html` (сохранения будут в хранилище браузера).

### Структура
```
electron/main.js        окно приложения (Electron)
src/index.html          интерфейс
src/js/core/            утилиты, кости
src/js/data/            расы, классы, снаряжение, заклинания, бестиарий, клетки, готовые карты
src/js/engine/          персонажи, геометрия поля и поиск пути, боевой движок, ИИ монстров
src/js/ui/              экраны: меню, редактор карт, персонажи, бестиарий, бой
tests/                  автотесты правил (node --test)
```
